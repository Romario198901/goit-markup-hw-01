# WebStudio Landing Page

A simple HTML landing page for a fictional digital studio called **WebStudio**.

## Project Overview

This project contains a single-page website built with plain HTML. The page includes:

- a responsive header and navigation
- a hero section with a call-to-action button
- a features section highlighting the studio's strengths
- a team section with staff profiles and images
- a footer with branding and messaging

## Files

- `index.html` — main landing page
- `images/` — image assets used by the team section
- `.gitignore` — Git ignore rules
- `prettierc.json` — code formatting settings

## Getting Started

To view the page:

1. Open `index.html` in your browser.
2. Alternatively, use a local web server if you want to serve the page over HTTP.

## Notes

- This project currently includes only the HTML structure.
- CSS styling can be added in a separate stylesheet or inline as needed.
